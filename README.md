# Деплой — таблицы (OpenDataLoader + проверка) для «Помогатора»

## Почему это не обычная Cloud Function
OpenDataLoader — Java-инструмент. Обычный деплой Python-файла в Cloud
Functions (как вы делали с `takeoff_pipeline.py`) не подойдёт — там нет
Java. Нужен **Cloud Run**: тот же принцип (загрузка через GitHub,
Google сам всё собирает), просто на основе Docker-образа с Python+Java
вместе, а не голого .py файла.

## Что в этой папке
- `main.py` — сама функция (`extract_and_verify_tables`)
- `verify_table.py` — модуль сверки «Итого»/«Всего» (копия из
  `takeoff_pipeline.py`, секция 8)
- `requirements.txt`
- `Dockerfile` — Python 3.11 + Java 17 (headless JRE, только для JVM
  под OpenDataLoader)

## Деплой через GitHub (тот же принцип, что и раньше)
1. Этот `cloud_function/` целиком — в отдельный репозиторий или подпапку
   существующего.
2. В Google Cloud Console → **Cloud Run** → «Создать службу» → «Непрерывно
   развёртывать из репозитория» → подключить GitHub-репозиторий, указать
   эту папку как корень сборки (Cloud Build сам найдёт `Dockerfile`).
3. Region — любой ближе к вам. Аутентификация — «Разрешить
   неаутентифицированные вызовы» (иначе браузер не достучится напрямую;
   если нужна защита — обсудим отдельно вариант с Firebase Auth).
4. После деплоя Cloud Run даст URL вида
   `https://ваш-сервис-abc123-uc.a.run.app` — его вставляете в поле
   «Cloud Function URL» в «Помогаторе».

## Проверить, что работает, до подключения к браузеру
```bash
curl -X POST https://ваш-сервис.../  -F "file=@Раздел_ПД4_2023-135_часть1_КР1_изм_3.pdf" -F "pages=48"
```
Должен вернуться JSON со списком таблиц и результатами сверки.

## Оценка объёма по массе (для таблиц без строки "Итого")
Некоторые спецификации (например, «Спецификация к схеме расположения свай»)
не содержат итоговой строки/колонки вообще — только построчный список марок
с количеством и массой единицы. В этом случае `verify_table()` сверять
нечего, но `main.py` автоматически пробует посчитать суммарный объём как:

```
Σ (Кол-во x Масса ед., кг) / плотность материала
```

Ищутся колонки, чей заголовок содержит "кол." / "кол-во" / "количество" и
"масса ед" / "масса, кг". Результат попадает в ответ отдельным полем
`mass_estimate` с явной пометкой, что это расчёт, а не значение с чертежа.

Плотность по умолчанию — 2500 кг/м3 (тяжёлый бетон/ж/б). Если нужно другое
значение (например, 7850 для металлопроката), передайте его отдельным полем
формы при запросе:
```bash
curl -X POST https://ваш-сервис.../ \
  -F "file=@сваи.pdf" \
  -F "density_kg_m3=7850"
```

## Стоимость
Cloud Run считает по факту использования (секунды выполнения), простаивая —
не платите вообще (в отличие от постоянно запущенного сервера). Один запрос
на страницу PDF занимает несколько секунд — для вашего объёма это копейки.
